## Principe de présentation
- Carte d'article : **FORMAT · NOM ÉDITORIAL DU CYCLE** (ex. « Les interrogatoires · La culture a un prix »).
- Menu : nom éditorial prioritaire et libellé économique technique discret pour l'orientation.
- Page du cycle : nom éditorial en titre et secteur technique en sous-titre.
- Répertoire de cycles : nom éditorial en titre, nomenclature et ambition en information secondaire.
- Recherche : retrouver les contenus indifféremment à partir du nouveau nom ou de l'ancien libellé.
- Le mapping est centralisé dans `editorialCycleNames` et `publicCycleLabel` de `media-prototype/src/lib/editorial.ts`.
- Le code historique `numerique-telecom` est rapproché de `numerique` uniquement pour l'affichage.

## Périmètre différé
Les **six familles** conservent leurs noms techniques actuels dans cette mise à jour : leur nouvelle identité fait l'objet d'une proposition distincte, non encore validée. Une fois approuvées, elles auront un mapping public séparé, sans changer leur code ni les regroupements de cycles.

Aucun manuscrit, statut de publication, métadonnée CMS, URL ou permalien n'est modifié.
